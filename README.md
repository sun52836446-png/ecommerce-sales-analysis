# ecommerce-sales-analysis
SQL + Python 电商销售数据分析项目，含全流程指标分析与可视化

## 项目简介
本项目基于电商平台订单数据，从销售趋势、地区分布和用户行为三个维度进行系统分析，构建可量化指标体系，为运营决策和策略优化提供数据支持。

**核心能力展示：**
- 数据清洗与处理（Python + Pandas）
- SQL 数据分析与指标计算
- 数据可视化（Matplotlib / Seaborn）
- 商业指标设计与业务解读
- 数据库建模（关系型星型模型）

---

## 数据集
项目使用数据表共 9 张：

| 数据表 | 说明 |
|--------|------|
| customers | 客户基础信息 |
| geolocation | 邮编对应经纬度信息 |
| orders | 订单生命周期记录（下单、发货、收货、状态） |
| order_items | 订单商品明细（商品、卖家、价格、运费） |
| order_payments | 支付方式与金额（GMV核心来源） |
| order_reviews | 用户评分与评论 |
| products | 商品属性信息（类别、尺寸、重量等） |
| sellers | 卖家信息 |
| category | 商品类别翻译表 |

数据库采用星型模型设计，以订单表为核心事实表，其余表作为维度表，提高查询效率和分析逻辑清晰性。

---

## 核心指标
1. **GMV**（平台成交总额）  
2. **客单价**（Average Order Value）  
3. **月销售趋势**（按月 GMV）  
4. **各州销售额排行**（市场结构）  
5. **活跃客户数**（用户规模）
