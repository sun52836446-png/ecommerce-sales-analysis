# ecommerce-sales-analysis
SQL + Python 电商销售数据分析项目，含全流程指标分析与可视化

## 项目简介
本项目基于电商平台订单数据，从销售趋势、地区分布和用户行为三个维度进行系统分析，构建可量化指标体系，为运营决策和策略优化提供数据支持。

**核心能力展示：**
- 数据清洗与处理（Python + Pandas）
- SQL 数据分析与指标计算
- 数据可视化（Matplotlib / Seaborn）
- 商业指标设计与业务解读
- 数据库建模（关系型星型模型）

---

## 数据集

> ⚠️ 注意：由于原始数据量较大，项目中 **未上传 CSV 数据和完整数据库文件 (`ecommerce.db`)**。  
> 本项目只包含 **SQL 脚本、Python 分析脚本和分析报告**。  

如果有真实数据，可将 CSV 放入 `data/` 文件夹，并运行 `scripts/run_analysis.py` 导入数据库和生成指标，可直接复现分析流程。

---

## 核心指标
1. **GMV**（平台成交总额）  
2. **客单价**（Average Order Value）  
3. **月销售趋势**（按月 GMV）  
4. **各州销售额排行**（市场结构）  
5. **活跃客户数**（用户规模）
